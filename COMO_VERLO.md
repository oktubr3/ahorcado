# 🎮 Respuesta: "Como puedo verlo en accion?"

## ⚡ RESPUESTA RÁPIDA

### Opción 1: Ver Online (5 Segundos) 🌐

```
👉 https://oktubr3.github.io/ahorcado/
```

**¡Abre ese enlace y ya está!** No necesitas instalar nada.

---

### Opción 2: Ver Local (2 Minutos) 💻

```bash
# 1. Descargar
git clone https://github.com/oktubr3/ahorcado.git
cd ahorcado

# 2. Ejecutar
python3 -m http.server 8000

# 3. Abrir navegador
# http://localhost:8000
```
