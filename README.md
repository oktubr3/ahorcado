### 👉 [CLICK AQUÍ PARA JUGAR ONLINE](https://oktubr3.github.io/ahorcado/) 👈

## 🎮 Características God-Level

### 🎯 Sistema de Dificultades
- **🟢 Fácil**: 10 vidas, palabras de 4-6 letras, 120 segundos
- **🔵 Normal**: 8 vidas, palabras de 7-10 letras, 90 segundos  
- **🟠 Difícil**: 6 vidas, palabras de 11-15 letras, 60 segundos
- **🔴 Imposible**: 4 vidas, palabras de 16+ letras, 45 segundos

### 📚 Diccionario Masivo
- **500+ palabras** organizadas en 10 categorías
- 🍎 Frutas (42 palabras)
- 🦁 Animales (50 palabras)
- 🌍 Países (50 palabras)
- ⚽ Deportes (45 palabras)
- 👨‍💼 Profesiones (50 palabras)
- 💻 Tecnología (49 palabras)
- 🏙️ Ciudades (53 palabras)
- 🎨 Colores (39 palabras)
- 🎸 Instrumentos (37 palabras)
- 🍕 Alimentos (41 palabras)

### 🎯 Sistema de Puntuación
- **10 puntos** por cada letra acertada
- **Multiplicadores** según dificultad:
  - Fácil: x1
  - Normal: x1.5
  - Difícil: x2
  - Imposible: x3
- **Bonus** por tiempo restante: 5 puntos/segundo
- **High Score** persistente guardado en localStorage

### 💡 Sistema de Pistas
- **3 pistas** disponibles por partida
- **Costo**: 20 puntos por pista
- Revela automáticamente una letra oculta
- Botón intuitivo en la interfaz

### ⏱️ Temporizador Dinámico
- Cuenta regresiva en tiempo real
- Tiempo límite varía según dificultad
- Visual actualizado cada 0.1 segundos

### 📊 Estadísticas Completas
- **Partidas jugadas** totales
- **Victorias y derrotas** acumuladas
- **Porcentaje de victoria**
- **Mejor puntuación** histórica
- **Racha actual** de victorias
- Todo guardado en localStorage

### ✨ Efectos Visuales Premium
- **Animaciones CSS** suaves y profesionales
- **Partículas** al acertar/fallar letras
- **Efecto confeti** al ganar con 50 partículas
- **Shake effect** al fallar
- **Gradientes** y sombras modernas
- **Transiciones** fluidas en todos los elementos

### ⌨️ Soporte de Teclado
- Escribe directamente con tu teclado físico
- No necesitas hacer clic en los botones
- Respuesta instantánea

### 🎨 Interfaz Mejorada
- Selector de dificultad con animaciones
- Selector de categorías con íconos
- Información del juego en tiempo real
- Diseño responsive optimizado
- Colores y tipografía profesional

## 🚀 Tecnologías Utilizadas
- HTML5
- CSS3 (con animaciones avanzadas)
- JavaScript Vanilla (ES6+)
- Tailwind CSS
- LocalStorage API
- Audio API

## 📱 Instalación Local
```bash
git clone https://github.com/oktubr3/ahorcado.git
cd ahorcado
# Abrir index.html en tu navegador o usar un servidor local
python3 -m http.server 8000
```

## 🎯 Cómo Jugar
1. Selecciona tu nivel de dificultad
2. Elige una categoría (o aleatorio)
3. ¡Adivina la palabra!
4. Usa pistas si las necesitas (costo: 20 pts)
5. Completa antes de que se acabe el tiempo
6. Compite contra tu mejor puntuación

## 🏆 Records
- Mantén una racha de victorias
- Supera tu mejor puntuación
- Estadísticas completas guardadas localmente
